# סיפורי משתמש (User Stories) - עוזר קולי על ESP32

קבוצה A2, קורס IoT, קיץ 2026.

**מטרת הפרויקט:** עוזר קולי על בקר זול (ESP32, ‏520KB זיכרון). מדברים איתו, הוא עונה בקול ושולט ברכיבים על הלוח. הבנת הדיבור בענן (OpenAI), וכל השאר על הבקר. מרכז בקרה בדפדפן מראה מה קורה ומאפשר לשנות הגדרות.

ההדגמות לפי הסדר, מהבסיסי להגדרות ולסטטיסטיקה. רשימה מקוצרת נמצאת גם במרכז הבקרה (כפתור Demo checklist). מי שמפעיל את המערכת בפעם הראשונה יכול ללחוץ Tour ולקבל סיור קצר במסך.

**תנאי מקדים - רשת:** כל ההדגמות על hotspot של טלפון (לא רשת הטכניון), ב-2.4GHz. הלוח מכיר את ה-hotspot מראש, מ-`SECRETS.h` או מכרטיס Wi-Fi network במרכז הבקרה (שם וסיסמה, בלי קימפול). החלפת הרשת מודגמת במקרה קצה 3 ב[רשימת מקרי הקצה](edge-cases-extended.md).
