# סיפורי משתמש (User Stories) - עוזר קולי על ESP32

קבוצה A2, קורס IoT, קיץ 2026.

**מטרת הפרויקט:** עוזר קולי על בקר זול (ESP32, ‏520KB זיכרון). מדברים איתו, הוא עונה בקול ושולט ברכיבים על הלוח. הבנת הדיבור בענן (OpenAI), וכל השאר על הבקר. מרכז בקרה בדפדפן מראה מה קורה ומאפשר לשנות הגדרות.

ההדגמות לפי הסדר: קודם הפיצ'רים העיקריים (שיחה בקול ושליטה בלוח בקול), אחר כך עוד דרכים לדבר, ובסוף הגדרות, עבודה בלי מחשב וסטטיסטיקה. רשימה מקוצרת נמצאת גם במרכז הבקרה (כפתור Demo checklist). מי שמפעיל את המערכת בפעם הראשונה יכול ללחוץ Tour ולקבל סיור קצר במסך.

**תנאי מקדים - רשת:** כל ההדגמות על hotspot של טלפון (לא רשת הטכניון), ב-2.4GHz. הלוח מכיר את ה-hotspot מראש, מ-`SECRETS.h` או מכרטיס Wi-Fi network במרכז הבקרה (שם וסיסמה, בלי קימפול).

**מקרי קצה:** העמודה "מקרי קצה" מפנה למספרים ב[רשימת מקרי הקצה](edge-cases-extended.md) שמדגימים באותו שלב. מקרי הרשת והחומרה (1, 3, 7, 8) מודגמים בבלוק נפרד לפני הסטטיסטיקה.
