# תוכנית ההדגמה - 25 דקות

קבוצה A2, קורס IoT, קיץ 2026. המסמך הזה בשבילנו: מה מכינים, באיזה סדר מדגימים, ומה עושים אם משהו לא עובד. הסדר הולך לפי [סיפורי המשתמש](user-stories.md) ו[מקרי הקצה המורחבים](edge-cases-extended.md) (מספרי מקרי הקצה כאן הם של הרשימה המורחבת), שמודפסים בשני עותקים. הרשימה המקורית שבדקנו: [edge-cases.md](edge-cases.md).

## יום לפני

- [ ] לצרוב את הקושחה האחרונה ולעבור פעם אחת על כל ה-Demo checklist במרכז הבקרה.
- [ ] לבדוק שהשעה נכונה (`What time is it?`, או השורה Board clock ב-Self-test). כדי שהשעון יעבור לבד לשעון קיץ, להוריד ב-`ESP32/parameters.h` את ההערה מהשורה `#define TIMEZONE_POSIX "IST-2IDT,M3.5.5/2,M10.5.0"` ולצרוב שוב.
- [ ] אם הכפתור והצלילים נבדקו על הלוח: להדליק ב-On the board itself את BOOT button ו-Status sounds.
- [ ] להטעין power bank (להדגמה בלי מחשב).
- [ ] בזמן החזרה, לשמור את הלוג (Save log to folder…). זה הגיבוי אם אין אינטרנט בהדגמה (ראו למטה).
- [ ] להדפיס 2 עותקים של סיפורי המשתמש ו-2 של מקרי הקצה, ועותק של [המדריך המהיר](quick-start.pdf) להשאיר ליד הלפטופ.
- [ ] להטעין את הלפטופ ואת הטלפון של ה-hotspot.

## 10 דקות לפני

- [ ] להדליק hotspot בטלפון, לחבר את הלוח ל-USB, לפתוח את `control_center/control_center.html` ב-Chrome וללחוץ Connect board.
- [ ] לחכות שכל הנורות ירוקות ולשמוע את ברכת הפתיחה.
- [ ] ללחוץ Self-test (ליד Board health): ה-LED מהבהב, צפצוף, וכל השורות עם ✓.
- [ ] לנקות: Clear בשיחה, Reset בסטטיסטיקה, "איפוס" ב-Demo checklist.
- [ ] להתחיל ממצב רגיל: עוצמה כ-60%, LED כבוי, Hands-free כבוי, סליידר האור על day.
- [ ] אם יש מסך גדול או מקרן: Stage view (מקש F) כשמדגימים שיחה.
- [ ] ברגע שמתחילים: Demo checklist ← "התחלת ההדגמה". בכותרת מופיע שעון עם השלב שבו צריך להיות לפי הטבלה למטה, והוא נהיה אדום אחרי 25 דקות.

## לתת לבוחנים להפעיל

עדיף שהבוחנים ינסו בעצמם. אם הם לא מכירים את המסך, ללחוץ **Tour**: סיור קצר של 9 תחנות שמסביר כל חלק. הכרטיס Try saying נותן להם משפטים מוכנים, וגם [המדריך המהיר](quick-start.md) המודפס. כדאי להזכיר שהכי טוב לדבר באנגלית (עברית עובדת, אבל פחות טוב), קרוב למיקרופון, ושאפשר לשאול כל שאלה, לא רק את הדוגמאות.

## אם משהו לא עובד

| מה קרה | מה עושים |
|---|---|
| נורית Wi-Fi אדומה / Offline | לבדוק שה-hotspot דלוק. אין צורך ב-Reset: הלוח מתחבר לבד. hotspot אחר: כרטיס Wi-Fi network. ה-Wi-Fi של הטכניון לא עובד עם הלוח |
| אין אינטרנט בכלל | Disconnect, ואז Replay a log… בטרמינל ולבחור את הלוג מהחזרה. מרכז הבקרה מנגן את השיחה כאילו היא קורית עכשיו. להגיד לבוחנים שזה לוג, לא חי |
| אין תשובה לשאלה | אחרי 15 שניות הלוח מוותר בעצמו, כותב למה, וחוזר ל-Ready. לשאול שוב (מקרה קצה 6) |
| העוזר לא הבין | לדבר קרוב יותר, ועדיף באנגלית. בבועה רואים מה הוא שמע, וזה עוזר להסביר |
| החדר רועש מדי | לכתוב את השאלה בשדה שמתחת ל-Talk וללחוץ Ask. הוא עונה בקול כרגיל (מקרה קצה 21) |
| Hands-free מופעל מרעש בחדר | להוריד את Sensitivity, או לכבות Hands-free ולהמשיך עם Talk |
| באנר אדום: הכבל התנתק | לחבר שוב. מרכז הבקרה מתחבר לבד, והלוח המשיך לעבוד בינתיים |
| באנר אדום: הלוח נעצר | ללחוץ על כפתור ה-Reset (EN) שעל הלוח (קורה רק אם משימת המיקרופון לא עלתה) |
| נורית SD אדומה | הלוח עובד בלי הקלטות. להכניס את הכרטיס ו-Reset, או להמשיך בלי (מקרה קצה 8) |
| השעה לא נכונה בשעה אחת | שעון קיץ: `TIMEZONE_POSIX` ב-`ESP32/parameters.h` (ראו "יום לפני"). להסביר ולהמשיך |
| הטיימר לא צלצל | הוא מחכה שהלוח יהיה פנוי. אם העוזר באמצע תשובה, הצלצול יגיע מיד אחריה |
