# מבחן משתמש

קבוצה A2, קורס IoT, קיץ 2026. הקורס מבקש מבחן עם משתמשים מבחוץ ושינויים בעקבותיו. המסמך הזה הוא התבנית: מה נותנים למשתמש לעשות, מה מודדים, ומה רושמים.

> **סטטוס: עוד לא בוצע.** למלא אחרי המבחן. לא לכתוב תוצאות שלא נמדדו.

## איך עורכים את המבחן

- 2-3 משתמשים שלא מכירים את הפרויקט (לא מהקבוצה).
- נותנים להם רק את [המדריך המהיר](quick-start.md) המודפס ואת המשימות שלמטה. לא עוזרים, אלא אם הם תקועים יותר מדקה (ואז רושמים את זה).
- רושמים לכל משימה: הצליח / הצליח בעזרה / לא הצליח, כמה זמן, ומה המשתמש אמר.
- שומרים את הלוג (Save log) של כל מבחן.

## המשימות

| # | המשימה למשתמש | מה בודקים |
|---|---|---|
| 1 | "תחבר את מרכז הבקרה ללוח ותבדוק שהכל תקין" | Connect, הנורות, Self-test |
| 2 | "תשאל את העוזר שאלה כללית" | Talk, דיבור באנגלית, הבנת התשובה |
| 3 | "תדליק את האור ותעמעם אותו לחצי" | כלים קוליים |
| 4 | "תבקש תזכורת בעוד דקה" | הטיימר, ההודעה בסוף |
| 5 | "תעבור למצב שבו לא צריך ללחוץ, ותשאל משהו" | גילוי של Hands-free |
| 6 | "תוריד את העוצמה, ותבדוק שהיא נשארת אחרי Reset" | פקדים ושמירה |
| 7 | "תחבר את הלוח לרשת אחרת" (hotspot שלהם) | כרטיס Wi-Fi network |
| 8 | "תמצא מה העוזר שמע בפקודה האחרונה" | לשונית ההקלטות |
