# User Test

Group A2, IoT course, Summer 2026. The course asks for a test with outside users and changes that follow from it. This document is the template: what the user is given to do, what is measured, and what is recorded.

> **Status: not done yet.** Fill in after the test. Do not write results that were not measured.

## How to run the test

- 2-3 users who do not know the project (not from the group).
- Give them only the printed [quick start guide](quick-start.md) and the tasks below. Do not help, unless they are stuck for more than a minute (and then write it down).
- For each task, write down: succeeded / succeeded with help / did not succeed, how long it took, and what the user said.
- Save the log (Save log) of each test.

## The tasks

| # | The task for the user | What is checked |
|---|---|---|
| 1 | "Connect the control center to the board and check that everything is OK" | Connect, the lights, Self-test |
| 2 | "Ask the assistant a general question" | Talk, speaking in English, understanding the answer |
| 3 | "Turn on the light and dim it to half" | Voice tools |
| 4 | "Ask for a reminder in a minute" | The timer, the message at the end |
| 5 | "Switch to the mode where you don't need to press anything, and ask something" | Discovering Hands-free |
| 6 | "Lower the volume, and check that it stays after a Reset" | Controls and saving |
| 7 | "Connect the board to a different network" (their hotspot) | The Wi-Fi network card |
| 8 | "Find what the assistant heard in the last command" | The recordings tab |
