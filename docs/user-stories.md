# סיפורי משתמש (User Stories) - עוזר קולי על ESP32

קבוצה A2, קורס IoT, קיץ 2026.

**מטרת הפרויקט:** עוזר קולי על בקר זול (ESP32, ‏520KB זיכרון). מדברים איתו, הוא עונה בקול ושולט ברכיבים על הלוח. הבנת הדיבור בענן (OpenAI), וכל השאר על הבקר. מרכז בקרה בדפדפן מראה מה קורה ומאפשר לשנות הגדרות.

ההדגמות לפי הסדר, מהבסיסי להגדרות ולסטטיסטיקה. אותה רשימה נמצאת גם במרכז הבקרה (כפתור Demo checklist). מי שמפעיל את המערכת בפעם הראשונה יכול ללחוץ Tour ולקבל סיור קצר במסך.

| 7 | משתמש | לשאול איזה חלק של היום עכשיו | העוזר יענה לפי האור בחדר | מזיזים את סליידר האור (מדמה את החיישן) לערך נמוך ושואלים `Is it day or night`. העוזר עונה `night`. מעלים את הערך ושואלים שוב. | |
| 8 | משתמש | שהעוזר יזכור מה אמרתי קודם | השיחה תהיה טבעית | אומרים `My name is Omri`, ואחר כך שואלים `What is my name`. | |

| 13 | משתמש | לשנות את הספים של יום, ערב ולילה | הם יתאימו לתאורה אצלי | משנים את הספים ולוחצים Apply thresholds. הנורית של החלק ביום מתעדכנת. | |
| 14 | משתמש | שההגדרות יישמרו | לא אצטרך לכוון מחדש כל פעם | לוחצים Reset בלוח. אחרי העלייה העוצמה, הבהירות וההגדרות של Hands-free נשארות כמו שהיו. | |
