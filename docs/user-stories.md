# סיפורי משתמש (User Stories) - עוזר קולי על ESP32

קבוצה A2, קורס IoT, קיץ 2026.

**מטרת הפרויקט:** עוזר קולי על בקר זול (ESP32, ‏520KB זיכרון). מדברים איתו, הוא עונה בקול ושולט ברכיבים על הלוח. הבנת הדיבור בענן (OpenAI), וכל השאר על הבקר. מרכז בקרה בדפדפן מראה מה קורה ומאפשר לשנות הגדרות.

ההדגמות לפי הסדר, מהבסיסי להגדרות ולסטטיסטיקה.

| 1 | משתמש | להדליק את המכשיר ולראות שכל הרכיבים תקינים | אדע שהוא מוכן לשיחה | מחברים לחשמל ולוחצים Connect במרכז הבקרה. נורות התקינות נהיות ירוקות (SD, מיקרופון ורמקול, Wi-Fi, שעון, OpenAI) והעוזר אומר ברכת פתיחה. | |

| 8 | משתמש | לשמוע שוב פקודה שאמרתי ותשובה שקיבלתי | אוכל לבדוק מה נקלט | בלשונית ההקלטות בוחרים פקודה אחרונה ומנגנים אותה מהמחשב, עם waveform. אפשר גם למחוק. | |
